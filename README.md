# 实验课签到系统

一个供助教 / 老师使用的小型实验完成登记系统，**以课程为中心**：创建课程的人就是课程管理员，管理员邀请助教加入课程，课程内的班级、实验、学生、完成记录对管理员和助教共享。学生做完实验找助教检查，助教按学号登记完成（自动记录服务器时间），并可随时在「总览」查看各班级 × 各实验的完成矩阵。

## 角色说明

| 角色 | 如何产生 | 能做什么 |
| --- | --- | --- |
| 全局超管 | `config.py` 里的初始管理员账号 | 进入「全局管理」查看/删除任何用户、任何课程；不管课程内部事务 |
| 课程管理员 | 创建课程的人（一个课程一人） | 管理该课程的班级、实验、学生（含导入）、生成邀请码、移除助教；也可登记、撤销、更正（改时间）、看总览 |
| 课程助教 | 通过邀请码加入（需本人确认） | 登记、撤销；不能修改时间、不能看总览、不能进管理页 |
| 普通用户 | 登录页自助注册 | 初始无课程，可创建课程或接受邀请 |

## 功能

- 课程：创建课程、我的课程列表（管理员/助教一目了然）、邀请码加入课程
- 「登记」页：选择班级 + 实验进入登记工作台，按学号查找学生，一键「登记完成」或「撤销」（自动记录服务器时间 + 操作人）
- 「更正」页（仅课程管理员）：撤销误登记，或修改完成时间
- 总览（仅课程管理员）：某班级 × 全实验的完成矩阵（完成格直接显示完成时间），并可导出 Excel
- 管理（仅课程管理员）：课程管理（成员与邀请、实验管理）、班级管理（创建班级，班级内导入学生、学生管理）
- 全局管理（仅全局超管）：查看/删除所有用户和课程
- 登记完成时自动记录操作人（登录账号的姓名）

## 安装（只需一次）

1. 安装 Python 3（<https://www.python.org/> ，安装时勾选 **Add to PATH**）
2. 在本目录打开命令行（或 PowerShell），执行：

   ```bash
   pip install -r requirements.txt
   ```

## 初始全局超管（部署前必做）

首次部署时先把 `config.example.py` 复制为 `config.py`（本地已有 `config.py` 则跳过此步），然后打开 `config.py`：

- 把 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 改成全局超管账号密码（首次启动时自动创建；之后每次启动都会确保该账号是超管）
- 把 `SECRET_KEY` 改成任意一长串随机字符

其他用户打开网页后点「注册」即可自行创建账号，无需管理员操作。

## 使用流程

1. **创建课程**：登录后点「创建课程」，创建者自动成为该课程的管理员。
2. **邀请助教**：管理员在「管理 → 成员与邀请」点「生成邀请码」，把码发给对方；对方登录后在课程列表页「加入课程」输入邀请码，看到课程信息后点「接受」即成为助教。邀请码 7 天有效、一次性，可随时撤销。
3. **日常使用**：管理员先导入学生名单、添加实验；助教上课时在「登记」页按学号登记完成；想看整体进度进「总览」。

## 启动（每次上课）

双击 `start.bat`，等待启动后，屏幕上会显示访问地址，例如：

```text
http://192.168.1.100:8000
```

把这个网址发给其他助教，用手机或电脑浏览器打开即可（需处于同一 WiFi / 内网）。
下课后直接关闭窗口即可，**数据不会丢失**。

## 数据与备份

所有数据存在本目录的 `data.db` 一个文件里。**备份 = 复制这个文件。**

升级到课程结构版本时，系统会在首次启动前自动生成一份带时间戳的备份（`data.db.bak-YYYYMMDD-HHMMSS`），并把旧数据合并进一个名为「实验课」的课程（归管理员所有）——同名班级/实验自动合并，学号冲突时保留管理员名下的学生。

> 注意：请**固定用同一台电脑当「签到主机」**，否则数据会分散到多台电脑、合不到一起。

## 导入文件格式

支持 `.xlsx`、`.xls`、`.csv` 三种格式，系统会**自动识别文件真实格式**（即使把 `.xls` 误存成 `.xlsx` 也能识别）。表头需包含「学号」「姓名」「班级」三列（列名可稍作变体，如 `student_no / name / class`），列顺序不限；班级列缺失时归入「默认班级」。学号列建议在 Excel 里设为「文本」格式，避免丢失前导 0。

> **学号在课程内唯一**：同一学号在同一课程内只能属于一个学生（跨班级也不允许重复）；不同课程之间的学号可以重复、互不影响。重复导入时——同一班级的同学号会更新其姓名；不同班级出现同一学号会被记为「学号冲突」并跳过。

示例：

| 学号     | 姓名 | 班级     |
| -------- | ---- | -------- |
| 20210001 | 张三 | 计科2101 |
| 20210002 | 李四 | 计科2101 |

## 常见问题

- **无法登录**：确认用户名和密码正确。全局超管账号见 `config.py` 里的 `ADMIN_USERNAME` / `ADMIN_PASSWORD`；其他用户用自己注册的账号登录。
- **看不到「管理」菜单**：只有课程管理员能看到；助教只能登记、更正、看总览。
- **邀请码无效**：邀请码 7 天有效且一次性，可能已被使用或过期/被撤销，找课程管理员重新生成一个。
- **别人访问不到**：确认你们在同一个 WiFi/内网，且主机的防火墙允许 8000 端口（Windows 首次运行会弹窗，选「允许访问」）。
- **想随时随地访问**：把整套代码放到一台云轻量服务器（阿里云/腾讯云）上运行即可，代码无需改动。
